## Handoff Protocol

1. The assigning agent fills in one narrowly scoped task, allowed files, acceptance criteria, and validation commands.
2. The worker reads `AGENTS.md`, `Ai-Tasks.md`, and this file before editing.
3. The worker records its approach, changes, tests, and blockers here.
4. The reviewer inspects the actual working-tree diff and test output.
5. The reviewer records findings or change requests here.
6. The task is complete only when the reviewer marks the status `approved`.
